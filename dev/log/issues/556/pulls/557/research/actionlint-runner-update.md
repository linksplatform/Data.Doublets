Reproduced with the current released actionlint 1.7.12 (official image digest b1934ee5f1c509618f2508e6eb47ee0d3520686341fec936f3b79331f9315667): a minimal job with `runs-on: ubuntu-26.04` fails with `label "ubuntu-26.04" is unknown`. This hosted runner has been GA since September 17, 2026: https://github.blog/changelog/2026-09-17-ubuntu-26-generally-available-and-latest-migration/ .

The downstream workaround in https://github.com/linksplatform/Data.Doublets/pull/557 uses the existing supported actionlint.yaml `self-hosted-runner.labels: [ubuntu-26.04]` configuration to extend known labels while retaining other syntax, expression and embedded ShellCheck/Pyflakes checks. The runner remains GitHub-hosted. Please add the label to the built-in runner schema and release the update (the existing related PRs appear to contain the necessary change).
