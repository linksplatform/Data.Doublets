# Existing components and migration choices

- NuGet Central Package Management: official NuGet/MSBuild support for one version per package, including transitive pinning, replaces repeated versions across projects: https://learn.microsoft.com/nuget/consume-packages/central-package-management . Adopted in Directory.Packages.props; lockfiles preserve integrity and locked restores.
- xUnit v3 framework 4.0.2 and adapter 4.0.1 replace v2. Reviewed https://xunit.net/docs/getting-started/v3/migration and https://xunit.net/releases/v3/4.0.0 . Executable test project and supported mtp-off package retain VSTest/coverlet collector integration on .NET 10; no test is skipped. All 479 tests pass.
- .NET 10 stable LTS SDK 10.0.403 (11 is still RC): registry release index and https://learn.microsoft.com/dotnet/core/compatibility/10 . Updated every project and isolated package consumer. Review C# 14 span overload resolution and generic-math behavior through the full storage regression suite.
- Modern Conan Center recipes for GoogleTest 1.18.0, Benchmark 1.10.0, GSL 5.0.1 and mio cci.20230303 replace frozen 2023 third-party recipes. Remove the old GTest precision cast, Benchmark pthread repair, cpuinfo/clog and CMake-minimum source rewrites entirely. Current upstream recipes provide their own metadata/build integration. C++20 already exceeds GoogleTest's new C++17 requirement; GSL 5's C++17 minimum is compatible. Official source: https://conan.io/center/recipes/gtest and the saved conandata files.
- pip's resolver report plus a shared constraints lock freezes the complete Python tool tree; no application package exists, so adding packaging-only metadata would misrepresent the repository. The Python 3.15 toolchain floor is explicit in Ruff/mypy and CI. Pyflakes 4 drops obsolete Python 3.9/3.10 support; no embedded checker API is used. Ruff's current formatter handles Python 3.14+ exception syntax. Conan and mypy CLI integrations remain covered by existing regression tests.
- cargo update, rustfmt, clippy and cargo-audit are existing upstream tools for the experimental Rust manifests. Both manifests now use the same reviewed current doublets-rs revision as the submodule. Edition 2024 and the exact stable 1.99.1 toolchain are explicit. Submodule-owned manifests remain maintained upstream; the superproject pins and audits that source instead of publishing untracked submodule edits.
- Tracked JavaScript and TypeScript application files are historical investigation fixtures under dev/log; maintained workflow JavaScript belongs to the pinned Actions. There is no package.json, application entrypoint, npm lockfile or missing runtime package to install. SHA-pinned Actions carry their own JavaScript runtime/dependencies. Do not add a failing Dependabot npm entry for nonexistent files. The obsolete changed-files PR #397 refers to a removed workflow; scripts/changes.py already uses git's actual event base without that dependency.
- Dependabot is already installed: extend it to every real supported ecosystem/directory. Renovate is an alternative, not an additional updater. Enabling the repository's existing GitHub auto-merge setting repairs the actual disabled-setting failure without changing branch protections or merging this PR.

- Conan 2.34 platform_tool_requires declares the checksum-installed current CMake 4.4.5 as a provided build tool, replacing a second older Conan CMake distribution: https://docs.conan.io/2/reference/config_files/profiles.html#platform-tool-requires . The native graph and lockfile resolve cmake/4.4.5#platform.

- Maintained kjanat/actionlint 1.17.0 implements current GitHub queue and self-repository references, unlike the original 1.7.12 release: https://github.com/kjanat/actionlint/releases/tag/v1.17.0 . Prefer native validation over custom schema checks, source rewriting or diagnostic filters. Keep ShellCheck 0.11.0 and locked Pyflakes 4.1.0; executable fixtures verify all three checkers. Rebuild identical release sources with current Go because the distributed binary embeds vulnerable Go 1.27.0; report this upstream.
- OSV Scanner 2.7.0 already parses Conan v2 locks and audits complete container images: https://github.com/google/osv-scanner/releases/tag/v2.7.0 . Adopt that supported parser rather than introduce a production dependency-name parser/API client. Retain a small investigation-only exact-commit probe for private native source aliases. Audit both the full native lock and the rebuilt workflow checker image in CI.
- .NET 10's framework package pruning removes obsolete System compatibility dependencies. Remove their unused central pins as well; locked restore confirms that no active package resolution changes. Current NuGet tooling owns this framework compatibility logic.
