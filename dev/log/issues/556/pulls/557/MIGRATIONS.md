# Major migrations and upstream features

| Migration | Primary migration/release references reviewed | Repository adaptation and verification |
|---|---|---|
| .NET 8 to 10; Microsoft.Extensions/System packages to 10 | [.NET 9 changes](https://learn.microsoft.com/dotnet/core/compatibility/9.0), [.NET 10 changes](https://learn.microsoft.com/dotnet/core/compatibility/10), [central transitive pinning](https://learn.microsoft.com/nuget/consume-packages/central-package-management) | Review generic-math shifts, span overload selection, obsolete APIs and platform requirements. All owned targets and consumers use net10.0. These projects do not use ASP.NET/Windows Forms affected APIs. Warnings-as-errors build, all storage tests, examples and isolated consumer cover actual APIs. Central version management removes repeated project pins. |
| xUnit v2 to v3 framework 4; adapter 3 to 4 | [Migration guide](https://xunit.net/docs/getting-started/v3/migration), [framework 4 release](https://xunit.net/releases/v3/4.0.0), [adapter 4 release](https://xunit.net/releases/visualstudio/4.0.0); saved release text | Use supported xunit.v3.mtp-off with an executable test project and current VSTest adapter, preserving the coverlet collector and all 479 tests. No assertions/tests disabled. |
| Roslyn 4 to 5.9 | [Roslyn breaking changes](https://github.com/dotnet/roslyn/blob/main/docs/Breaking%20API%20Changes.md), research/roslyn-migration5.md | BenchmarkDotNet's compilation path is covered by actual Dry benchmark generation and execution. No direct Roslyn API wrapper to retain. |
| ClrMD 3 to 4.2 and TraceEvent 3 to 4 | [ClrMD 4 changes](https://github.com/microsoft/clrmd/blob/main/doc/Migrating4.md), [4.2 changes](https://github.com/microsoft/clrmd/blob/main/doc/Migrating42.md), research/clrmd-migration4.md; [TraceEvent release](https://github.com/microsoft/perfview/releases), research/traceevent-release.json | Review DataTarget/custom-target changes and newer platform baseline. Consumers use BenchmarkDotNet rather than custom diagnostic wrappers. Full benchmark executable is rebuilt/executed on Linux/Windows; no obsolete calls or warnings. PerfView application UI/platform changes do not introduce a repository UI. |
| Python 3.12 to 3.15; mypy 1 to 2; Pyflakes 3 to 4 | [3.13 porting](https://docs.python.org/3.13/whatsnew/3.13.html), [3.14 porting](https://docs.python.org/3.14/whatsnew/3.14.html), [3.15 porting](https://docs.python.org/3.15/whatsnew/3.15.html#porting-to-python-3-15), research/mypy-changelog-source.txt, research/pyflakes-news.rst | Current tools run on Python 3.15.2; formatter now uses the supported multi-exception syntax. Close HTTPError response streams explicitly; regression checks closure. No direct mypy/Pyflakes internals are used. All script typing/lint checks and 110 regression tests run with current tools. |
| Rust edition 2021 to 2024 | [Edition guide](https://doc.rust-lang.org/edition-guide/rust-2024/index.html), [rustup explicit installation](https://github.com/rust-lang/rustup/issues/4836) | Both owned probes compile with edition 2024, stable 1.99.1 and warnings denied. Upstream submodule keeps its own edition. Explicit rustup installation removes deprecated implicit behavior. |
| CMake 3 to 4.4 | [4.0 removed features](https://cmake.org/cmake/help/latest/release/4.0.html#deprecated-and-removed-features), [Conan platform tools](https://docs.conan.io/2/reference/config_files/profiles.html#platform-tool-requires) | Remove old minimum-policy workaround; current upstream recipes already support current CMake. Raise repository floor honestly, install checksum-verified official distribution and declare it a provided Conan tool. Full native build/package consumer validates policies. |
| GSL 4 to 5; GoogleTest support baseline | [GSL 5 release](https://github.com/microsoft/GSL/releases/tag/v5.0.0), [GoogleTest 1.18](https://github.com/google/googletest/releases/tag/v1.18.0) | Review checked iterators, narrowing and not_null changes. Existing C++20 requirement meets current C++17 baseline. Current recipes remove obsolete metadata; native tests and analyzers verify real usages. |
| GCC/Clang current diagnostics | [GCC 16 changes](https://gcc.gnu.org/gcc-16/changes.html), [Clang release notes](https://releases.llvm.org/23.1.0/tools/clang/docs/ReleaseNotes.html) | Fix invalid abstract interfaces rather than silence template diagnostics. Seven base-reference dispatch checks reproduce before/after behavior; major C++ changeset acknowledges virtual layout changes. |
| checkout 6 to 7, setup-dotnet 6, setup-python 6 to 7 | Current releases in research/github-actions-*.json and [official Action repositories](https://github.com/actions) | Hosted runners are current and satisfy Action runtime requirements. Preserve checkout credential isolation, global SDK selection and exact Python selection. Full real jobs exercise new Actions rather than emulate their JavaScript internals. |
| upload-artifact 4 to 7; download-artifact 4 to 8 | [Upload 7](https://github.com/actions/upload-artifact/releases/tag/v7.0.0), [Download 8](https://github.com/actions/download-artifact/releases/tag/v8.0.0), saved current sources | Native v8 digest mismatch failure remains enabled. Use supported skip-decompress to avoid the unreleased deprecated unzip implementation; retain bounded safe Python extraction and NODE_OPTIONS=--throw-deprecation. Real upload/download/extract/diff round trip validates contents. No forked Action or ignored deprecations. |
| Current workflow schema and security analysis | [Self-repository reference support](https://github.com/rhysd/actionlint/issues/711), [maintained fork](https://github.com/kjanat/actionlint/releases/tag/v1.17.0), [OSV Scanner](https://github.com/google/osv-scanner/releases/tag/v2.7.0) | Native maintained actionlint understands queue and $/ reusable references, replacing handwritten queue validation, input rewriting and error filters. Keep embedded ShellCheck/Pyflakes active; five positive/negative probes prove their behavior. OSV's existing Conan v2 parser replaces a proposed production custom parser. Rebuild unchanged checker source with patched Go; audit resulting image. |

Package updates without a major change use the same supported CLI/API and the full ecosystem checks. Platform.Collections.Methods 1.0.0 and the incompatible statistical/data major migrations are documented as upstream constraints rather than weakening parents' constraints or skipping tests. The inventory records removed legacy xUnit compatibility packages; none are reintroduced.
