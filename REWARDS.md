# Open Source User Rewards Program

## First Big Open Source User Reward

The first large open-source project that becomes a user of [Doublets](https://github.com/linksplatform/Data.Doublets) will receive **5555 RUB** (or its equivalent) from us.

### Eligibility Conditions

To be eligible for this reward, your project must meet ALL of the following requirements:

1. **GPL-compatible license** - Your project must use a license that is compatible with the GPL license
2. **Published on GitHub** - The project repository must be hosted on GitHub and publicly accessible
3. **555+ stars** - The repository must have more than 555 stars
4. **1+ year old** - The repository must have existed for at least one year
5. **Integration proof** - You must demonstrate actual usage of Doublets in your project

### How to Apply

To claim this reward:

1. **Integrate Doublets** into your project (add it as a dependency and use it meaningfully)
2. **Create an issue** or comment on [issue #254](https://github.com/linksplatform/Data.Doublets/issues/254) with:
   - Link to your project repository
   - Proof of Doublets integration (code examples, commits, documentation)
   - Verification that you meet all eligibility conditions
3. **Wait for review** - We will verify your submission and contact you regarding the reward

### Verification Process

Our team will verify:
- ✅ Repository license compatibility with GPL
- ✅ GitHub repository accessibility and star count
- ✅ Repository creation date (minimum 1 year)
- ✅ Meaningful integration of Doublets in your project
- ✅ Project quality and legitimacy

### Reward Details

- **Amount**: 5555 RUB or equivalent in your preferred currency
- **Payment method**: To be arranged based on your location and preferences
- **Processing time**: Up to 30 days after verification
- **Limitation**: Only ONE project will receive this reward (first come, first served)

### Status

🟢 **AVAILABLE** - This reward is currently available and waiting for the first qualifying applicant.
